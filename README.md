# ACSTF

ACS Athlete Development: the separate Codex/GitHub build.

The app lives in [acs-athlete-development](acs-athlete-development/README.md).

```sh
cd acs-athlete-development
npm test
npm start
```

Requires Node 24. Includes coach/athlete accounts, server-enforced permissions, and server-side SQLite storage. See the app README for setup, migration, and deployment requirements. The original hosted ChatGPT app is unchanged.
